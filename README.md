# Hotel Management Database

This project sets up a hotel management system using MariaDB v10.6. The database structure supports multiple hotels, with tables for managing guests, reservations, rooms, staff, and payment information. This `README` provides instructions on how to set up and use the database.

## Prerequisites

- **MariaDB v10.6**: Ensure MariaDB v10.6 or a compatible version is installed on your system.
- **SQL Client**: Use a SQL client or command-line interface to interact with the database.

## Files Included

- `hoteldb_s1_2024.sql`: Contains the SQL commands to create the database schema and tables.
- `hoteldb_s2_2024.sql`: Contains additional SQL queries, functions, and procedures for managing and querying the database.
